# Kampüs Etkinlik

Kampüsteki etkinlikleri duyurmak, listelemek ve yönetmek için hazırlanmış statik bir HTML web uygulamasıdır.

## Sayfalar

- [index.html](index.html) — Ana sayfa: proje tanıtımı ve yaklaşan etkinlikler.
- [etkinlikler.html](etkinlikler.html) — Tüm etkinliklerin listelendiği ve aylık programın gösterildiği sayfa.
- [etkinlik-detay.html](etkinlik-detay.html) — Seçilen bir etkinliğin detaylarının gösterildiği sayfa.
- [etkinlik-ekle.html](etkinlik-ekle.html) — Yeni etkinlik eklemek için form içeren sayfa.
- [etkinlik-guncelle.html](etkinlik-guncelle.html) — Var olan bir etkinliği güncellemek için form içeren sayfa.

## Kullanım

Depoyu klonladıktan sonra `sprint1` klasöründeki `index.html` dosyasını bir tarayıcıda açarak projeyi görüntüleyebilirsiniz.

## Teknolojiler

- HTML5
- CSS (dahili `<style>` blokları ile)
